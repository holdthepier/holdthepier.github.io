Où est ma sauvegarde ?

La sauvegarde se trouve sur votre appareil, dans le dossier du jeu. Supprimer le jeu supprime aussi la sauvegarde. Une sauvegarde de l'appareil (iCloud ou ordinateur) inclut le dossier du jeu : en restaurant l'appareil, vous retrouvez votre progression. Les sauvegardes ne sont pas synchronisées entre appareils.

Dans quelles langues est le jeu ?

Le jeu existe en dix langues : turc, anglais, allemand, français, espagnol, portugais (Brésil), italien, russe, japonais et coréen. Au premier lancement, il prend la langue de votre appareil ; vous pouvez la changer dans le jeu, sous Options > Langue.

Pas de son

Si le mode silencieux du téléphone est activé, le jeu ne fait aucun son. Les effets sonores et l'ambiance se règlent séparément dans les options du jeu.

J'ai trouvé un problème

Quand vous nous écrivez, merci d'indiquer :

  • ce qui s'est passé et ce que vous faisiez,
  • le modèle de votre appareil et votre version d'iOS / iPadOS,
  • la version du jeu (dans le jeu : Options > Licences, tout en haut),
  • si possible une capture ou un enregistrement d'écran.
