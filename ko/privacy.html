Hold the Pier

개인정보 처리방침

최종 업데이트: 2026년 11월 12일

요약

Hold the Pier는 개인 정보를 수집하지 않으며 저희에게는 서버가 없습니다. 게임에는 광고, 분석, 추적, 자체 계정이 없으며 어떤 데이터도 저희에게 전송되지 않습니다. 게임은 Apple의 Game Center를 위해서만 인터넷에 연결되며 Game Center 없이도 오프라인으로 게임할 수 있습니다.

Game Center

Game Center에 로그인되어 있으면 기록, 업적, 이름은 Apple의 Game Center에 저장됩니다. 저희는 서버에 아무것도 저장하지 않습니다. 리더보드 화면에서는 Game Center에서 가져온 다른 이용자의 이름과 프로필 사진을 보여 줍니다. Game Center는 iPhone의 설정 > Game Center에서 끌 수 있습니다.

기기에 저장되는 정보

진행 상황(골드, 스킬 트리, 설정, 진행 중인 런)은 기기의 게임 전용 폴더에만 저장됩니다. 기기 밖으로 나가지 않으며 저희는 볼 수 없습니다. 게임을 삭제하면 저장 데이터도 삭제됩니다.

기기 백업(iCloud 또는 컴퓨터)이 켜져 있으면 게임 폴더도 백업에 포함됩니다. 백업은 Apple 서비스와 사용자가 관리하며 저희에게 전달되지 않습니다.

권한

게임은 카메라, 마이크, 사진, 위치, 연락처 권한을 요청하거나 사용하지 않습니다.

리더보드의 동료 탭을 위해 게임은 Game Center 동료 리스트에 접근 권한을 요청합니다. 거부하면 전체 리스트만 보입니다.

아동

게임은 아동을 포함해 누구의 개인 정보도 수집하지 않습니다.

변경 사항

데이터를 수집하는 기능(예: 광고나 앱 내 구입)이 추가되면, 해당 버전이 출시되기 전에 이 페이지를 업데이트해 무엇을 왜 수집하는지 밝힙니다.
